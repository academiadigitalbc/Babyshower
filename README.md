# La dulce espera de Adrián

Micrositio estático de invitación para Baby Shower, listo para publicarse en GitHub Pages.

## Publicación

1. Sube estos archivos a la rama principal de un repositorio de GitHub.
2. En **Settings → Pages**, selecciona **Deploy from a branch**.
3. Elige la rama principal y la carpeta `/ (root)`, y guarda los cambios.

No requiere instalación, compilación ni dependencias externas. Para revisarlo localmente, abre `index.html` en el navegador o ejecuta:

```bash
python3 -m http.server 8000
```
